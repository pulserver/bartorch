Examples#

Executed when the documentation is built: every figure and number comes from the code on the page. Each page has an Open in Colab button, so you need nothing but a browser to run it. The ideas behind them are in Explanations, and every function they call is in API reference.

Eleven lessons from a k-space tensor to a learned reconstruction, read in order (Course).

Contents

2. From k-space to an image

3. Coil sensitivities

Coil sensitivity estimation and its effect on the reconstruction

4. Joint reconstruction of image and sensitivity maps

Joint estimation of image and coil sensitivities from a small calibration region

5. Choosing a regularizer

Tikhonov, wavelet and total-variation regularization; regularization weight

6. Custom encoding and solver

Encoding operator and solver, identical to pics

7. Basics of non-Cartesian imaging

Trajectories, NUFFT, density compensation, point spread function

8. Radial SENSE

Golden-angle radial SENSE

Model-based \(T_2\) mapping from raw data

10. Plug-and-play reconstruction

Plug-and-play with a pretrained denoiser

11. Training an unrolled network

Unrolled network trained through ADMM

Requirements#

The scripts need a built bartorch, brainweb-dl, which downloads the BrainWeb phantoms several examples build their images from, and matplotlib and cmap for the figures:

pip install bartorch brainweb-dl matplotlib cmap

The learned-regularization lessons and tours additionally require lightning, torchio, monai and deepinv, and the corrections tours PyHySCO; the Course and Tours pages name what each needs.
